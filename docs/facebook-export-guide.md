# Exporting your Facebook data

1. Open Facebook **Settings & privacy**, then **Settings**.
2. Open **Your information and permissions** and choose **Download/Export your information**.
3. Select your own profile and choose **Download to device**.
4. Select Messages; optionally select Friends, Comments, Reactions and Posts.
5. Choose JSON format, the desired date range, and create the export.
6. Download the ZIP from Meta and upload it on the Imports page.

Never share the archive: it may contain private conversations. This application does not log into Facebook, scrape profiles, or infer profile visitors.
